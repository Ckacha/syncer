# syncer
Something to sync your youtube and spotify playlists!

Syncer a small flash web app that's able to move playlists between YouTube and Spotify(and the other way around :D)

If you paste playlist link, syncer will searche the other service for each song, then gives every match a trust score based on the title, artist, song length and channel. It also catches covers, remixes, live versions and instrumentals that don't line up! 
The confident matches go in automatically, but iffy ones wait for you to tick them on a review page, and bad ones are skipped (you can still see them). 

Additionally, you can create custom automations based on certain fields! Check out how you can build them on the [guide](https://syncer.ckacha.dev/guide)

As spotify has certain rules about letting people using custom dev apps, this program requires that you put yourself on a whitelist. It'll work with youtube to youtube playlists, but if you want to use it's features with spotify, DM @iamalive on the Hack Club Slack!

If you want to set this up yourself, you'll need to have spotify preimum, but beyond that refer to the local host [guide](https://syncer.ckacha.dev/localhost)
